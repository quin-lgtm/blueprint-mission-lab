# Motion Rules

1. The water may move continuously; the typography should feel still.
2. GSAP updates plain scroll/proxy values. Pixi reads values in the ticker.
3. No Pixi object creation inside scroll callbacks.
4. Reduce-motion mode preserves the composition but reduces drift, mist, shimmer, and scroll intensity.
5. The waterwheel rotates only when its section is active enough to make narrative sense.
6. Particles should read as water/mineral/ion motion, not confetti.
