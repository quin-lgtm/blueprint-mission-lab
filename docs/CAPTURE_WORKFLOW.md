# Capture Workflow

Run the page:

```bash
npm install
npm run dev
```

Capture still frames:

```bash
npm run capture:frames
```

Capture a scroll-through video:

```bash
npm run capture:video
```

Outputs are written to:

```text
captures/frames/
captures/video/
```

This exists so the page can be reviewed visually through Chromium instead of judged from code alone.
